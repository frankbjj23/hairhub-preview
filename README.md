# The Hair Hub public preview

A public redesign preview for The Hair Hub in Ridgefield, New Jersey.

[Open the website](https://frankbjj23.github.io/hairhub-preview/)

This repository contains the compiled website, local fonts, and original-shop imagery used by the preview. Source development is maintained separately. Font licenses and asset provenance are included in the fonts and images directories.

The preview links to the shop's current SQUIRE booking pages, Google/SQUIRE review pages, and Instagram. It does not change hairhubusa.com or manage bookings.
